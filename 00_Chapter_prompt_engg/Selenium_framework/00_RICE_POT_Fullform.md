# RICE-POT Prompt Engineering Framework

The **RICE-POT** framework is an advanced, structured prompt engineering methodology designed to elicit high-precision, production-ready output from Large Language Models.

| Letter | Component | Description | Purpose in Prompt Engineering |
| :---: | :--- | :--- | :--- |
| **R** | **Role** | Persona, industry domain, and seniority level (e.g., 15+ years QA Automation Lead). | Calibrates technical depth, idioms, and industry standards. |
| **I** | **Instructions** | Specific directives, positive rules, and negative constraints (`[Critical]`, `[Don't]`). | Defines required functionality, assertions, and strict prohibitions. |
| **C** | **Context** | Application details, user flows, environment URLs, and business rules. | Provides real-world domain grounding (e.g., Salesforce CRM login flow). |
| **E** | **Example** | Few-shot code snippets, structural templates, or syntactic patterns. | Anchors the exact coding style, class structure, and annotation usage. |
| **P** | **Parameters** | Quality metrics, accuracy criteria, and non-functional requirements. | Enforces clean architecture, zero code smells, and performance. |
| **O** | **Output** | Exact list of artifacts, file names, packages, and delivery format. | Restricts response to requested deliverables without irrelevant fluff. |
| **T** | **Tone** | Communication profile (e.g., technical, enterprise-grade, concise). | Ensures professional, unambiguous technical language. |
